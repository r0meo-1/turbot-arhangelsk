# TurBot Agent Desk

Version: **0.3.0**

Бесплатное внутреннее расширение для Edge / Chrome, которое объединяет рабочий поток турагента вокруг TurBot.

## Что умеет MVP

- постоянная боковая панель;
- карточка клиента;
- быстрые кнопки Tourvisor PRO / Sletat PRO / Qui-Quo / TurBot / VK Натальи;
- добавление текущей страницы в подборку;
- на любом сайте: выделить текст -> ПКМ -> **Добавить в TurBot Agent Desk**;
- локальная подборка до 30 элементов;
- отправка клиента и до 10 выбранных вариантов в TurBot;
- заявка сохраняется в существующей базе `website_leads` и доставляется Наталье тем же durable delivery flow;
- MDT для этого не нужен.

## Рабочий день менеджера

Версия 0.3.0 добавляет CRM-контур из реального процесса турагента:

- **Что делать сегодня** — единая очередь Telegram / VK / сайта;
- история заявки с исходными параметрами и attribution;
- append-only история предложенных отелей и цен;
- реакции клиента на каждый вариант: дорого / думает / другой вариант / подходит / отказ;
- журнал контактов и заметок;
- follow-up задачи: подбор, отправка вариантов, звонок, проверка цены, авиабилеты, виза, документы, следующий контакт;
- результат заявки: продано / потеряно / пауза;
- данные VK остаются в отдельной VK SQLite, но Agent Desk агрегирует их в одну менеджерскую очередь.

Все CRM-действия проходят через bearer-защищённые `/agent-extension/*` API. Клиент расширения не выбирает путь к базе данных и не получает серверные/provider credentials.

## Мини-CRM

Расширение показывает последние заявки из TurBot и позволяет вести простой статус:

- Новая;
- В работе;
- Ждём клиента;
- Продано;
- Потеряно.

К каждой заявке можно сохранить короткую заметку менеджера и дату следующего контакта. Список лидов можно выгрузить в CSV для Excel/Google Sheets. Эти данные остаются в локальной SQLite TurBot на сервере, поэтому отдельная подписка MDT для базового lead-management не требуется.

Это не замена бухгалтерии, документооборота или полноценного back-office MDT. Но для ежедневного цикла «лид → подбор → менеджер → статус» MVP закрывает основную задачу бесплатно.

## Безопасность

Расширение не содержит:

- пароли Tourvisor / Sletat;
- JWT/API keys провайдеров;
- MDT credentials;
- production pairing token.

Для отправки лидов используется отдельный pairing-token Agent Desk.

Самый простой способ подключения:

1. написать боту с Telegram-аккаунта `ADMIN_ID` команду `/agentdesk`;
2. скопировать показанный pairing-token;
3. вставить его один раз в секции **Подключение** расширения.

По умолчанию TurBot выводит отдельный HMAC-токен, производный от серверного `BOT_TOKEN`. Сам Telegram bot token браузеру не передаётся и из pairing-token обратно не восстанавливается.

При необходимости администратор сервера может переопределить токен переменной `AGENT_EXTENSION_TOKEN`.

Pairing-token хранится только в `chrome.storage.local`.

## Установка в Microsoft Edge

1. Открыть `edge://extensions/`.
2. Включить **Режим разработчика**.
3. Нажать **Загрузить распакованное**.
4. Выбрать папку `agent-extension`.
5. Закрепить **TurBot Agent Desk** на панели.
6. Нажать иконку — откроется боковая панель.

Для Chrome процедура та же через `chrome://extensions/`.

## Почему не скрейпим Tourvisor/Sletat DOM

MVP намеренно не парсит внутреннюю верстку агрегаторов. Менеджер сохраняет страницу или выделенный текст явным действием. Это:

- устойчивее к изменению DOM;
- не требует широких host permissions;
- не собирает данные со страниц без действия агента;
- работает на сайтах любых операторов.

Следующий этап — site adapters только для тех сервисов, где официальная интеграция или стабильный DOM действительно оправдывают поддержку.
